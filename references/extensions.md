# Extensions in Carve 0.2

The 0.2 [extension contract](../spec/spec/0.2/extensions.md) defines registration, matching, tree transformation, resolution, rendering, and writing. An extension must preserve a valid core fallback. Do not treat a host's registered extension as available in another renderer. In carve-js the standard extensions (for example `details`, `spoiler`, `wikilinks`, `smartQuotes`, and the fenced renderers) come from `@markup-carve/carve/extensions` and work only when the host registers them. The spec catalog names `carve.codeGroup`, `carve.details`, `carve.spoiler` and `carve.spoilerBlock`, `carve.mathBlock`, and `carve.fencedRender.mermaid` (C2-X-061 to C2-X-069); `code-group` claims a div only when its body holds nothing but code blocks. The wiki form is `:wiki[Page]` or `:wiki[Page|Display]`, and `:cite[a; b]` names several keys.

0.2 has no `headingLevelShift()` extension; the core render option `headingShift` replaces it and runs before every extension transform, so the level options of `tableOfContents`, `headingPermalinks`, and `headingNumbers` name the shifted levels (with a shift of 1, `headingPermalinks({ levels: [1] })` matches no heading).

The standard tabs extension groups tab panels and has its own registration and output rules. Its renderer takes a host option `mode`: `css` (default, radio inputs) or `aria` (WAI-ARIA buttons and panels, the host ships the switching script); the group is claimed only when every block in it is a `::: tab`. Verify it in the target host. Named divs such as `::: note` and ordinary classes are core document structure, not a guarantee that a host has a specialized renderer. For math rendering, diagrams, embeds, and other host features, check the registered extension and its loss diagnostics before promising output.

An extension may return HTML the host cannot inspect. Trust and sanitization remain host responsibilities. Use the host's URL policy and raw HTML decision; do not infer either from the source alone. See [quality and safety](quality-and-safety.md).
